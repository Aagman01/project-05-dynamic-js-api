# Dynamic JavaScript DOM Logic & RESTful API Client

## 📌 Project Overview

This project is a dynamic product explorer built using HTML, CSS, and modern JavaScript ES6+.

The application fetches live product data from a public REST API and displays it dynamically without requiring a full-page reload.

Users can search, filter, and sort products while their preferences are stored using browser LocalStorage.

---

## 🚀 Features

- Fetches live product data using REST API
- Uses JavaScript `async/await` and `fetch()`
- Dynamic DOM manipulation
- Real-time product search
- Category-based filtering
- Product sorting
- LocalStorage for client-side state
- Loading skeleton UI
- Error handling with retry functionality
- Responsive design for desktop and mobile
- No full-page reload during filtering or searching
